# 🔵 Nodeo — YouTube Notes Maker (Python)

Nodeo is a lightweight Python-based tool that converts **YouTube videos into clean, structured notes** using transcripts and AI summarization.

---

## 🚀 Features
- Input a YouTube URL  
- Fetch transcript automatically  
- Generate clear notes and key points  
- Fast and minimal Python API  
- No frontend or JavaScript required  

---

## 🛠️ Tech Used
- Python  
- YouTube Transcript API  
- AI text-generation API  

---

python main.py
